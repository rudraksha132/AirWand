Android: one-time Chrome setting (needed for motion sensors)

Chrome blocks motion sensors on pages that are not HTTPS. Open chrome://flags/#unsafely-treat-insecure-origin-as-secure on the phone, paste the addresses (separated by commas, copy them with the button below), set it to Enabled and tap Relaunch. The address must match exactly, port included, so all variants are listed. If the PC's IP address changes, add the new one; the short name never changes.

The first time the PC's firewall may ask to allow AirWand on private networks. Allow it.

iPhone

Safari needs HTTPS for motion sensors, so Wi-Fi from a web page does not work on iPhone. Use the native AirWand iPhone app, or Bluefy with Bluetooth.
